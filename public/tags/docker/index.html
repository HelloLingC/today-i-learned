#docker Linux 使用zsh - Aug 12, 2024

先查看当前的shell：

$ echo $SHELL
/bin/bash

安装zsh:

$ sudo pacman -S zsh zsh-completions

Making zsh the default shell

List all installed shell:

$ chsh -l

将/bin/zsh设为默认：

$ chsh -s /bin/zsh
